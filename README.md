Week 05 Work 04 – Product Form



Description

A Windows Forms application developed using C# and .NET Framework.



This project demonstrates the use of common Windows Forms controls through an interactive Product Form.



Features

\- Automatic barcode generation

\- Product information input

\- Product category selection

\- Product origin selection (Local or Abroad)

\- Active product status

\- Automatic markup calculation

\- Input validation

\- Save, Clear, and Cancel button events

\- Keyboard shortcuts for Save and Cancel



Technologies Used

\- C#

\- Windows Forms

\- .NET Framework

\- Visual Studio



How to Run

1\. Download or clone this repository.

2\. Open the `.sln` file using Visual Studio.

3\. Build the solution.

4\. Run the application.
